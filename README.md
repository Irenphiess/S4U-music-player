# S4U 文件夹音乐播放器

使用 Godot 4.3 打开本目录的 `project.godot`，再进行手动导出。

## 音乐库与格式

「文件 → 选择音乐库…」选择总文件夹。每个直接子文件夹是一张专辑，专辑名取文件夹名，歌名取文件名（不含扩展名），自然排序。增删音乐后使用「刷新音乐库」。

识别 MP3、WAV、OGG/OGA（Vorbis）、FLAC、M4A、AAC、AIF/AIFF、CAF。M4A 的 AAC／ALAC 音频现在优先通过播放器进程内的 macOS Core Audio 解码，不依赖 Godot 原生识别 M4A，也不需要安装第三方播放器或插件。受 DRM 保护或损坏的文件无法通过这种方式播放。解码只使用临时文件，不改动原音乐；长文件解码时可能短暂等待。

## 播放控制

- 空格：播放／暂停，在播放器主窗口内优先于按钮的默认空格操作，不会再次点击上一次操作的按钮。
- 普通 F7、F8、F9：上一首、播放／暂停、下一首。F7/F8/F9、空格及系统媒体控制会让对应按钮短暂显示原有按下图像，然后恢复；不会额外触发一次操作。
- Mac 顶排媒体键：通过系统远程播放命令控制。播放时向 macOS「播放中」提供曲名、专辑、时长、进度及播放／暂停状态；系统面板也可操作前后曲和进度。
- 最右侧按钮是保持状态的随机开关。点击开关本身不切歌；按下时，前后切歌和自动换歌随机选择当前专辑里的其他可播放歌曲；抬起时按顺序播放。模式会保存。

播放器已移除旧的原始媒体键重复处理路径，改由 macOS 分配媒体控制目标。其他软件如果自行安装全局媒体键监听，仍可能响应同一个按键；本应用不会修改其他软件设置。

## 菜单

| 操作 | 快捷键 |
| --- | --- |
| 文件 → 选择音乐库… | ⌘O |
| 文件 → 打开音乐库文件夹 | ⇧⌘O |
| 文件 → 刷新音乐库 | ⌘R |
| 显示 → 显示专辑名称和歌曲数量 | ⇧⌘A |
| 显示 → 显示歌曲序号和名称 | ⇧⌘T |
| 编辑 → 均衡器 → 均衡器… | ⌘E |
| S4U Folder Music → 设置… | ⌘, |

「设置…」提供简体中文、繁體中文、English、日本語、Français、Deutsch、Español、Italiano、Português (Brasil)、한국어，即时切换并记住选择。首次使用根据系统语言选择，不支持的系统语言默认使用英语。简体中文使用独立中文翻译表，不再回退为英文。菜单、提示和设置窗口随之翻译；你自己的专辑名、歌曲名不翻译。

设置和均衡器窗口均已放大，文字及控件随当前屏幕的缩放比例调整，允许手动调整大小；移动到不同缩放比例的屏幕时重新适配。

## 均衡器

「编辑 → 均衡器」可直接选用平直、蓝调、Disco、重低音、摇滚、人声、古典或自定义预设。预设是本项目提供的常用听感曲线，不是音频文件自带的风格标签。

打开均衡器窗口后，可开启／关闭效果，并分别调整 10 个频段（每段 −12 到 +12 dB）以及前级增益（−18 到 0 dB）。预设自动预留增益余量。手动调节会保存为自定义曲线，切换预设后仍可重新选回；设置重启后保留。提高频段增益时，可以降低前级增益以避免声音过载。

## 窗口

单指在播放器非按钮区域按下并拖动，可以移动窗口。拖动期间离开窗口不取消操作，松开按压后停止。窗口顶部左侧是翻页控件；「显示」菜单可以分别隐藏上方专辑信息和下方歌曲信息。

大头针选中时记住最新窗口位置和大小，重启后恢复；未选中时下次启动使用默认大小与居中位置。大头针状态独立保存。缩放采用可扩展透明画布，避免 Retina 尺寸取整造成窄黑边。

## 源码组件与检查范围

- `player_preferences.gd`：语言、设置窗口、10 段均衡器及预设。
- `addons/macos_media_keys`：macOS Core Audio 解码、MediaPlayer「播放中」和应用菜单的设置入口。目录内包含完整源码、Godot 接口头文件、构建脚本和 Apple Silicon／Intel 通用动态库。导出时保留整个目录，继续使用自己的应用签名设置。
- 原生组件已完成双架构编译；一次加载检查确认原生连接和进程内 M4A 解码成功，并据此修正了 Godot 4.3 均衡器频率接口的兼容问题。本轮按要求不进行反复功能回归；真实音乐文件、系统「播放中」面板及各硬件媒体键的最终体验由你的手动运行确认。

## 本轮修改范围

本轮仅编辑源码和翻译内容，按要求未运行播放器、未编译、未执行任何测试，也未打包导出。

## 控制菜单

「控制」位于「编辑」和 macOS 的「窗口」菜单之间，按顺序提供：暂停、播放、上一首、下一首、提升音量、降低音量、乱序播放，支持全部 10 种界面语言。

暂停与播放分别执行，不会反向切换。前四项会显示对应播放／切歌按钮的按压反馈。系统音量每次调整 6 个百分点，范围 0–100，提高非零音量时解除系统静音；不改动播放器自身音量或均衡器增益。音量菜单不触发＋／−按钮的视觉反馈；这两个按钮仍用于窗口缩放。不支持软件音量控制的输出设备会显示提示。

乱序播放是勾选项，与 CD 机最右按钮的保持状态双向同步：勾选／按下为乱序，取消勾选／抬起为顺序。切换本身不立即换歌，状态重启后保留。
